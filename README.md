# CV 实习准备自检清单

## 一、基础能力检查

### Python
- [ ] 能熟练写函数和类
- [ ] 能读懂常见 Python 代码
- [ ] 能处理 CSV / JSON / 图片路径
- [ ] 能写脚本做到批量处理数据

### NumPy
- [ ] 知道数组运算基础
- [ ] 能做简单数据处理与矩阵运算
- [ ] 能理解数据形状和广播

### OpenCV
- [ ] 能读图和保存图
- [ ] 能进行 resize / crop / rotate
- [ ] 能做灰度转换和二值化
- [ ] 知道边缘检测和滤波基础

### PyTorch
- [ ] 能写 Dataset 和 DataLoader
- [ ] 能写训练和验证流程
- [ ] 知道 nn.Module 的基本用法
- [ ] 会保存和加载模型

---

## 二、CV 关键知识检查

### CNN
- [ ] 知道卷积、池化、padding、stride
- [ ] 知道特征图和滤波器的关系
- [ ] 知道常见经典网络：LeNet / AlexNet / VGG / ResNet

### 任务理解
- [ ] 能区分分类、检测、分割
- [ ] 知道 IoU、mAP、Dice 的基本含义
- [ ] 知道目标检测和识别的区别

### 训练流程
- [ ] 知道 train / val / test 分割
- [ ] 会处理数据增强
- [ ] 知道过拟合与欠拟合的区别
- [ ] 会做基本调参

---

## 三、项目能力检查

- [ ] 有 1 个完整的 CV 项目
- [ ] 能解释数据集来源和处理过程
- [ ] 能说明模型选择理由
- [ ] 能说明训练过程和参数设置
- [ ] 能说明评估指标和结果
- [ ] 能说清楚项目存在的问题和改进方向

---

## 四、面试准备检查

- [ ] 能说清自己的项目
- [ ] 能解释卷积和 CNN 原理
- [ ] 能解释检测 / 分割的区别
- [ ] 能说出常见评估指标含义
- [ ] 能回答“为什么选这个模型”
- [ ] 能回答“项目做得不好的原因”

---

## 五、达到“能投 CV 实习”的最低标准

如果你完成以下 8 项，就基本能开始投递：

- [ ] Python 基础没问题
- [ ] PyTorch 能训练小模型
- [ ] OpenCV 基础能用
- [ ] 知道 CNN 基础
- [ ] 知道图像分类/检测/分割中的一种
- [ ] 会看指标：Accuracy / IoU / mAP 等
- [ ] 有至少 1 个完整项目
- [ ] 能讲清楚项目和面试问题

---

## 六、投递前建议

- [ ] 做好 GitHub 项目展示
- [ ] 把代码和 README 组织好
- [ ] 准备 1～2 分钟自我介绍
- [ ] 准备 3 分钟项目讲解
- [ ] 准备常见 CV 面试题答案

---

## 七、最终判断

如果你不是“研究级”水平，但能做到上面这些，通常已经具备 CV 实习投递能力了。

关键不是“知道全部模型”，而是：
- 你会做
- 你会讲
- 你会评估
- 你能站在项目上回答问题
